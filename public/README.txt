PROYECTO MULTRA E.U.

Archivos:
- index.html: página principal.
- login.html: acceso administrativo de demostración.
- dashboard.html: panel de trámites.
- assets/img/logo-multra.png: logo preparado a partir de la imagen suministrada.
- assets/img/robot-multra.png: robot del chatbot.

USO
1. Abre index.html en el navegador.
2. El botón Login abre login.html.
3. El login actual es demostrativo y abre dashboard.html.
4. En el dashboard puedes crear, editar, eliminar y buscar trámites por cédula o placa.
5. Los trámites se guardan en localStorage del navegador.

IMPORTANTE PARA PRODUCCIÓN
- Configura el número oficial en la constante WHATSAPP dentro de index.html.
- El login NO es autenticación segura. Para uso real requiere backend, base de datos, sesiones y control de acceso.
- localStorage es solo para prototipo/local. Para varios equipos o usuarios se requiere base de datos.
